# 👻 GhostOS — Enter the Unknown

**GhostOS** est un faux système d'exploitation web inspiré des ordinateurs des années 90. Explore une interface rétro-futuriste, utilise un terminal interactif et découvre les secrets d'un système mystérieux.

🌐 **Essayer GhostOS :** [Lancer le système](https://nitrox-creator.github.io/GhostOS/)

## ✨ Fonctionnalités

- 🖥️ Bureau virtuel interactif
- 💻 Terminal avec commandes personnalisées
- 📁 Fichiers et dossiers virtuels
- 🔍 Secrets et énigmes à découvrir
- 👻 Ambiance mystérieuse et effets rétro
- ⚙️ Paramètres et personnalisation
- 💾 Sauvegarde locale de la progression

## 🚀 Utilisation

Aucune installation n'est nécessaire.

1. Ouvre [GhostOS](https://nitrox-creator.github.io/GhostOS/).
2. Explore le bureau virtuel.
3. Lance le terminal et teste les commandes disponibles.
4. Examine les fichiers et les journaux.
5. Cherche les indices cachés et découvre les secrets du système.

## 🌐 Hébergement

GhostOS est hébergé gratuitement avec GitHub Pages.

Le projet fonctionne directement dans un navigateur compatible, sans serveur dédié.

## 🔒 Sécurité et confidentialité

GhostOS est une simulation fictive d'un système d'exploitation.

- Il ne remplace pas le système d'exploitation réel de l'ordinateur.
- Les fichiers virtuels ne sont pas les fichiers réels de l'utilisateur.
- Les données locales peuvent être conservées dans le navigateur.

Créer une expérience interactive et immersive qui mélange informatique rétro, exploration et énigmes.

## Mode secret

Le bureau `GHOSTOS // RESTRICTED` se découvre en recoupant les indices présents dans les fichiers virtuels, les journaux et le terminal. La commande d’ouverture et ses réponses ne sont pas données ici; `hint` fournit un indice facultatif sans révéler la solution.

Après le déverrouillage, **RETOUR AU BUREAU NORMAL** permet de revenir au bureau d’origine. Le terminal restreint propose `help`, `hint`, `decrypt`, `archives`, `events` et `normal`; ses trois énigmes se résolvent dans l’ordre. Les archives classifiées sont en lecture seule.

Le déverrouillage, les énigmes, les indices découverts et le journal d’événements sont sauvegardés séparément dans `ghostos.secret.v1` du stockage local. Dans **Paramètres**, **Réinitialiser uniquement le mode secret** efface uniquement cette progression. La réinitialisation complète de GhostOS efface également le mode secret.

Les pages, scripts et styles utilisent des chemins relatifs; le mode secret fonctionne ainsi aussi sur GitHub Pages sous `/GhostOS/`.
