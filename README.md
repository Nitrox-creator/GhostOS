# GhostOS
👻 GhostOS est un faux système d'exploitation rétro-futuriste. Explore un bureau interactif, utilise un terminal, découvre des fichiers secrets et résous des énigmes mystérieuses. 🖥️ Créé en HTML, CSS et JavaScript, il fonctionne dans ton navigateur et peut être hébergé gratuitement sur GitHub Pages.
